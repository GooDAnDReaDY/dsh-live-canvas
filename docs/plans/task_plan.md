# Техническое задание и план реализации: dsh-live-canvas

## 1. Цели и назначение
Предоставление встроенного в браузер интерактивного холста (Live Preview Canvas) для рендеринга генерируемых агентом веб-страниц, React-компонентов, SVG-графики и диаграмм Mermaid с поддержкой мгновенного hot-reload по SSE и инспектора элементов.

## 2. Архитектура решения
- **Серверный роут `PreviewServer`**: регистрируется через `ctx.webServer` (`/dsh-live-canvas/sandbox/*`, `/dsh-live-canvas/events`, `/dsh-live-canvas/api/*`) и отдает изолированную песочницу со строгой политикой CSP.
- **Модуль `EventHub`**: рассылает SSE-события в iframe для мгновенного hot-reload и синхронизации сессий.
- **Хранилище `PreviewStore`**: управляет сессиями предпросмотра в памяти с LRU-вытеснением и буфером инспекций DOM.
- **Транспайлер `transpiler.js`**: на лету оборачивает HTML, React JSX, SVG, Mermaid и Markdown в готовые веб-документы.
- **Браузерная панель `LiveCanvasWorkspace` и карточка `PluginCard`**: монтируется в UI DeepSeek Harness, поддерживает переключение разрешений (375px/768px/1280px/100%) и инспекцию DOM по клику.
